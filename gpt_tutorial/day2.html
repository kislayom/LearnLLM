1. Where we are

Day 1 built the spine: predict P(next token | previous), via embeddings → self-attention → softmax → cross-entropy, trained by gradient descent. Today we fill in the rest of a real transformer block and the machinery that actually trains it well: position, residuals, LayerNorm, multiple heads, the feed-forward net, the Adam optimizer, the learning-rate schedule, and how we generate text.

2. Positional embeddings — giving order to a "bag of tokens"

Attention is permutation-invariant: by itself it treats the input as an unordered set — "dog bites man" and "man bites dog" would look identical! So we add a learned position vector to each token embedding, encoding where each token sits:

x = TokenEmbedding[id] + PositionEmbedding[pos]

Learned vs sinusoidal. The original transformer used fixed sinusoidal functions of position; GPT-2 and our code use a learned nn.Embedding(block_size, d). Modern models often use RoPE (rotary) which rotates Q/K by position — better at generalizing to longer contexts. All solve the same problem: inject order.

3. Residual connections — the gradient highway

Each sub-layer computes x + f(x) instead of just f(x). This "skip connection" lets the input flow straight through, so very deep stacks stay trainable: during backprop the gradient has an unbroken path back to early layers (it doesn't have to squeeze through every transformation), which prevents vanishing gradients.

x = x + Attention(LayerNorm(x)) x = x + FeedForward(LayerNorm(x))

4. LayerNorm — keeping activations on a sane scale

As signals pass through many layers their scale can drift, destabilizing training. LayerNorm normalizes each token's vector to mean 0 and variance 1 (across its features), then applies a learned scale γ and shift β so the network can still choose the scale it wants:

LN(x) = γ · (x − μ) / √(σ² + ε) + β μ = mean(x), σ² = var(x) over the feature dimension

We apply LN before each sub-layer ("pre-norm", as in GPT-2). It's like auto-adjusting the volume on every layer so nothing blows out or fades to silence.

5. Multi-head attention — several "spotlights" at once

One attention head can only focus one way. Multi-head attention runs h heads in parallel, each with its own smaller Q/K/V, so different heads can specialize — one might track the subject of a verb, another nearby punctuation, another long-range references. Their outputs are concatenated and projected back:

head_i = softmax(Q_i·K_iᵀ / √d_k) · V_i MultiHead = Concat(head_1, …, head_h) · W_O (d_k = d / h)

6. The feed-forward network — per-token "thinking"

Attention moves information between tokens; the feed-forward network then processes each token independently. It's a 2-layer MLP that expands to 4× width, applies a non-linearity, and projects back — this is where a lot of the model's raw "knowledge" capacity lives:

FFN(x) = Linear(4d → d) ( GELU ( Linear(d → 4d)(x) ) )

7. The optimizer — from SGD to Adam

Plain gradient descent uses the same step rule for every parameter. Adam improves it with two running averages, giving each parameter its own adaptive step:

m ← β₁·m + (1−β₁)·g # momentum: smoothed gradient direction v ← β₂·v + (1−β₂)·g² # variance: typical magnitude of this param's grad θ ← θ − η · m̂ / (√v̂ + ε) # big steps where grads are small/steady, small where noisy
  • Momentum (m): averages recent gradients → smooths out noise, powers through flat spots.
  • Per-parameter scaling (v): divides by the gradient's typical size → every parameter learns at a sensible rate.
  • AdamW adds decoupled weight decay (gently shrinks weights → regularization).

9. Generation — turning probabilities into text

To generate, we feed the context, take the last position's logits, and pick a next token. How we pick controls the style:

MethodWhat it doesEffect
Greedy (argmax)Always take the most likely token.Safe but repetitive/dull.
TemperatureDivide logits by T before softmax.Low T → focused; high T → random/creative.
Top-kKeep only the k most likely; sample among them.Cuts off the long tail of nonsense tokens.
Top-p (nucleus)Keep the smallest set whose probs sum to p.Adaptive cutoff; popular default.

10. The training loop & what to expect

for step in range(max_iters):
    xb, yb = get_batch("train")        # random chunks; yb = xb shifted by 1
    logits, loss = model(xb, yb)       # forward pass → cross-entropy loss
    optimizer.zero_grad()
    loss.backward()                    # backprop: compute every gradient
    optimizer.step()                   # AdamW update: θ ← θ − η·m̂/(√v̂+ε)
  • Initial loss ≈ log(|V|) (~4.17 for ~65 chars) — the random-guess baseline. If it's wildly off, something's wrong.
  • Loss should fall steadily; watch train vs val to spot overfitting (val stops improving while train keeps dropping).
  • Generated text evolves: random chars → letter clusters → real words → phrase-like structure.

12. Day-2 glossary & references

Positional embedding
A vector added to each token encoding its position, since attention is otherwise order-blind. Learned, sinusoidal, or rotary (RoPE).
Vaswani et al. 2017 · RoPE
Residual connection
x + f(x) skip connection; keeps gradients flowing through deep stacks.
He et al. 2015 (ResNet)
LayerNorm
Normalize each token vector to mean 0 / var 1 over features, then learned scale+shift.
Ba et al. 2016
Multi-head attention
Several attention heads on d/h-sized slices in parallel, concatenated and projected — lets heads specialize.
Vaswani et al., §3.2.2
GELU
Smooth non-linearity used in the feed-forward net (a softer ReLU).
Hendrycks & Gimpel 2016
Adam / AdamW
Adaptive optimizer using momentum (m) and per-parameter variance (v); AdamW decouples weight decay.
Adam · AdamW
Warmup + cosine decay
Ramp the learning rate up, then cosine-decay it to a floor — stabilises early training, refines late.
SGDR (cosine)
Temperature / top-k / top-p
Knobs controlling randomness when sampling the next token from the logits.
Holtzman et al. 2019 (top-p)
