📚 Lessons & your progress

Progress is saved in your browser as you tick off sections inside each lesson.

🚀 Run the model

Everything you need is in this folder. Train a tiny GPT in a few minutes:

pip install torch              # CPU build is fine
python get_data.py             # tiny shakespeare (or: tinystories, sherlock)
python get_data.py --list      # see all dataset options
python train.py                # trains, prints loss, then generates a sample

Watch the initial loss start near log(|V|) (~4.17 for ~65 chars), fall steadily, and the generated text drift from gibberish toward real English.
