1. The big picture — one function, predicting the next token

An LLM is a single function estimating P( next token | all previous tokens ) Run it repeatedly — feed its own output back in — and it generates text. That feedback loop is what autoregressive means. Here is the whole pipeline we'll build:

2. Tokenize & embed — turning letters into vectors

Computers do maths on numbers, not letters. Tokenization maps each character to an integer id from a fixed vocabulary. Each id is then looked up in an embedding matrix E (shape |V| × d) to get a learned vector. Looking up row i is mathematically identical to multiplying a one-hot vector by E:

embedding(i) = oneHot(i) · E (picks row i of E)

3. Softmax — turning scores into probabilities

The model outputs logits (raw, unbounded scores). Softmax converts them into a probability distribution — all values ≥ 0, summing to 1. The exp makes everything positive and sharpens differences, so the model can focus on the most likely tokens:

softmax(z)ⱼ = exp(zⱼ) / Σₖ exp(zₖ)

4. The loss — cross-entropy (how wrong are we?)

We know the true next token. If the model gave it probability p, the loss is −log(p). Perfect (p=1) → 0 loss; confident-and-wrong (p→0) → huge loss. Minimizing this over all text = maximum likelihood.

L = −log( p(correct token) ) # cross-entropy for a one-hot target

5. Learning — gradient descent down the loss valley

The gradient ∇θL points uphill (steepest increase). To reduce loss we step the opposite way, scaled by the learning rate η. Backpropagation computes that gradient for millions of parameters in ~one pass.

θ ← θ − η · ∇θL # repeat on random mini-batches (stochastic GD)

6. Self-attention — the heart of the transformer

Each token builds three vectors via learned projections: a Query (what I want), a Key (what I offer), and a Value (the info I share). A token finds relevant context by comparing its query against every key with a dot product, softmaxing the scores into weights, and taking a weighted average of values:

Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V

Why divide by √d?

A dot product sums d terms, so its magnitude grows with d. Large scores push softmax into a near one-hot, flat region where gradients vanish (nothing learns). Dividing by √d normalizes the variance back to ~1, keeping softmax "soft" and trainable.

7. The causal mask & the T×T grid

Q·Kᵀ produces a T×T grid: entry (i, j) = "how much should token i attend to token j". For next-token prediction a token must not see the future, so we set those cells to −∞ before softmax (which makes their weight 0). Only the lower triangle survives.

8. Why attention is "quadratic" — O(T²)

Because every token compares with every token, the work scales with the area of that T×T grid: T². Double the length → 4× the work; 10× → 100×. Compare that to a linear O(T) operation:

T (tokens)Comparisons (T²)vs previous

2,0004,000,000×4 (length ×2)

Optimisations (from your question): causal masking already drops ~half; sparse/local attention → O(T·w); linear attention → O(T); FlashAttention keeps the maths but crushes the memory cost; the KV cache avoids redoing past work during generation.

9. The transformer block — multi-head + residuals + LayerNorm

Real models run several attention heads in parallel (each can specialize — one tracks subjects, another punctuation, …), concatenate them, and project back. Each block wraps attention and a feed-forward network with residual connections (x + f(x), so gradients flow) and LayerNorm (stabilizes the scale).

10. Glossary & references

Autoregressive model
Predicts the next value from its own previous values (next token from previous tokens).
Wikipedia — Autoregressive model
Chain rule (probability)
P(x₁..ₜ)=Π P(xᵢ|x<ᵢ); lets one next-token model score whole sequences.
Wikipedia — Chain rule
Tokenization
Splitting text into units and mapping each to an integer id.
tiktoken
Vocabulary (|V|)
The fixed set of possible tokens; its size sets embedding-table and output widths.
Byte-Pair Encoding (BPE)
Subword tokenizer that greedily merges frequent adjacent pairs; common words → one token, no out-of-vocabulary.
Wikipedia · Sennrich 2015
Embedding
A learned vector for a token (a row of matrix E, |V|×d). Lookup = one-hot · E.
Wikipedia — Word embedding
Logits
Raw unbounded output scores before softmax (one per token).
Wikipedia — Logit
Softmax
softmax(z)ⱼ = exp(zⱼ)/Σₖexp(zₖ): scores → probabilities (≥0, sum 1); exp sharpens differences.
Wikipedia — Softmax
Cross-entropy loss
L=−log p(correct); minimizing it = maximum likelihood. Perplexity=exp(L).
Wikipedia — Cross-entropy
Maximum likelihood
Pick parameters that make the observed data most probable (= minimize negative log-likelihood).
Wikipedia — MLE
Perplexity
exp(loss) — roughly how many tokens the model is confused between.
Wikipedia — Perplexity
Gradient descent
θ ← θ − η·∇θL; step opposite the gradient to lower the loss.
Wikipedia — Gradient descent
Learning rate (η)
The step size in gradient descent. Too big → diverge; too small → slow.
Backpropagation
Chain rule of calculus applied backward to get all gradients in ~one pass. PyTorch's loss.backward().
Wikipedia — Backprop
Adam / AdamW
Optimizer adapting per-parameter step size via momentum + gradient magnitudes; AdamW decouples weight decay.
Kingma & Ba · AdamW
Self-attention
Each token = weighted sum of (past) values, weighted by query–key similarity: softmax(QKᵀ/√d)V.
Vaswani et al. 2017
Query / Key / Value
Three learned projections: Query = what I want, Key = what I offer, Value = info passed on.
Vaswani et al., §3.2
Dot product
a·b=Σaᵢbᵢ: a single number measuring vector alignment; the attention similarity score.
Wikipedia — Dot product
Causal mask
Set future positions' scores to −∞ before softmax so each token attends only to itself and the past.
Quadratic cost O(T²)
Attention compares every pair, so compute/memory grow with the square of length T.
Wikipedia — Time complexity
Sparse / local attention
Attend to a subset (window w + global tokens) → O(T·w). May miss long-range links.
Longformer · BigBird
Linear attention
Approximate/drop softmax so the T×T matrix never forms → O(T). Loses some sharp focus.
Linformer · Performer
FlashAttention
Exact attention computed in fast on-chip memory tiles → much faster, less memory (same O(T²) maths).
Dao et al. 2022
KV cache
Cache past keys/values during generation so each new token costs O(T), not O(T²) redone.
Feed-forward network (MLP)
Per-token two-layer network (usually 4× wider) after attention; lets each token process gathered info.
Residual connection
x + f(x): adds a layer's output back to its input so gradients flow through deep stacks.
He et al. 2015 (ResNet)
LayerNorm
Normalizes each token vector to mean 0 / variance 1 (then scales) to stabilize training.
Ba et al. 2016

train.py (core)

import torch, torch.nn as nn
from torch.nn import functional as F

class Head(nn.Module):                       # one attention head
    def __init__(self, head_size):
        super().__init__()
        self.key = nn.Linear(n_embd, head_size, bias=False)
        self.query = nn.Linear(n_embd, head_size, bias=False)
        self.value = nn.Linear(n_embd, head_size, bias=False)
        self.register_buffer("tril", torch.tril(torch.ones(block_size, block_size)))
    def forward(self, x):
        B, T, C = x.shape
        k, q = self.key(x), self.query(x)
        wei = q @ k.transpose(-2, -1) * k.shape[-1] ** -0.5     # Q.Kt / sqrt(d)
        wei = wei.masked_fill(self.tril[:T, :T] == 0, float("-inf"))  # causal mask
        wei = F.softmax(wei, dim=-1)                            # weights sum to 1
        return wei @ self.value(x)                             # weighted sum of V

class Block(nn.Module):                       # one transformer block
    def __init__(self, n_embd, n_head):
        super().__init__()
        head_size = n_embd // n_head
        self.sa  = MultiHeadAttention(n_head, head_size)
        self.ff  = FeedForward(n_embd)
        self.ln1 = nn.LayerNorm(n_embd); self.ln2 = nn.LayerNorm(n_embd)
    def forward(self, x):
        x = x + self.sa(self.ln1(x))          # residual around attention
        x = x + self.ff(self.ln2(x))          # residual around feed-forward
        return x
